# ⚡ Quick Start - Get Your Website Running in 10 Minutes!

## ✅ Pre-Launch Checklist

Follow these steps to get your Vastuvriksha website up and running:

### Step 1: Installation (2 minutes)

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open http://localhost:5173 in your browser ✅

### Step 7: Add Your First Project (5 minutes)

Go to **Projects** tab:

Click "+ Add Project" and fill in:

- [ ] Title: (Your project name)
- [ ] Category: Residential or Commercial
- [ ] Location: City name
- [ ] Year: 2024
- [ ] Status: Completed
- [ ] Description: Brief project description

#### How to Add Image:
1. Go to https://imgur.com
2. Click "New post"
3. Upload project photo
4. Right-click image → "Copy image address"
5. Paste in Image URL field

**Click "💾 Save All Changes"** ✅

---

### Step 8: Test Your Website (2 minutes)

Visit each page and check:

- [ ] Home page looks good
- [ ] About page has your content
- [ ] Services are displayed
- [ ] Projects show up
- [ ] Contact form is there
- [ ] Footer has correct info
- [ ] Mobile view works (resize browser)

---

### Step 9: Change Admin Password (1 minute)

**For Security - Do This!**

1. Open: `src/pages/Admin.jsx`
2. Find line 12: `const ADMIN_PASSWORD = 'vastuvriksha2024';`
3. Change to: `const ADMIN_PASSWORD = 'your_new_secure_password';`
4. Save file
5. Restart dev server (Ctrl+C, then `npm run dev`)

---

### Step 10: Build & Deploy (5 minutes)

When ready to go live:

```bash
# Build for production
npm run build
```

**Deploy to Netlify (Easiest):**
1. Go to https://app.netlify.com/drop
2. Drag the `dist` folder
3. Done! You'll get a URL like: https://your-site.netlify.app

**Connect Your Domain:**
1. In Netlify, go to Domain Settings
2. Add custom domain: vastuvriksha.com
3. Follow DNS instructions from Netlify
4. Wait 24-48 hours for propagation

✅ **Your website is LIVE!**

## 💡 Pro Tips

1. **Content First**: Plan all content before starting
2. **Professional Photos**: Use high-quality images only
3. **Mobile-First**: Always check mobile view
4. **Regular Updates**: Add new projects monthly
5. **Backup Data**: Take screenshots of admin panel
6. **Test Everything**: Click every button and link
7. **Get Feedback**: Show to friends before launch
8. **SEO Matters**: Use descriptive titles and text
9. **Social Proof**: Add client testimonials later
10. **Stay Active**: Update website at least monthly
