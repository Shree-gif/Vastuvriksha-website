## 🆘 Need Help?

### Common Questions

**Q: Node.js not installed?**
A: Download from https://nodejs.org - Get LTS version

**Q: "npm not recognized" error?**
A: Restart terminal after installing Node.js

**Q: How do I add images?**
A: Admin panel → Projects → Click "📁 Upload Image"

**Q: Changes not saving?**
A: Click "💾 Save All Changes" button at bottom

**Q: How to change admin password?**
A: Edit `src/pages/Admin.jsx` line 13, rebuild, redeploy

**Q: Website looks broken?**
A: Clear browser cache (Ctrl+F5) or try incognito

**Q: How to update after deployment?**
A: Make changes, rebuild (`npm run build`), re-drag `dist` folder
